# Dung Beetle Dash: 100 Tiers

**Play Online:** https://watchdogitsme.github.io/dung-beetle-dash/

A single-file, zero-dependency HTML5 Canvas arcade game featuring 100 tiers, 5 dynamic biomes plus unlockable scenery packs, boss encounters, stackable mutations, and an Evolution Lab for permanent upgrades.

## Controls

- **Move:** `WASD` or `Arrow Keys`
- **Pause:** `Esc` or `P`
- **Audio / Pause Controls:** Available in the sidebar HUD (`SFX`, `Music`, `Pause`)

## Project Structure & Deployment

- **`Beetal dash.html`** — Complete self-contained HTML/CSS/JS game (can also be opened directly in any desktop browser).
- **`.github/workflows/pages.yml`** — Automatically deploys `Beetal dash.html` as `index.html` to GitHub Pages on pushes to `main`.
